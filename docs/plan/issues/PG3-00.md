## Objetivo
Que las cuatro máquinas corran lo mismo. Si no, el jueves se pierden horas en un «en la mía anda».

## Contexto
- D-05: Ollama local con `qwen2.5:3b`, temperatura 0, con LangChain (`ChatOllama`) como cliente del LLM.
- ARQUITECTURA §5: cada uno usa **su propio** Neo4j, no hay base compartida.
- El repo es **público**: las credenciales van solo en `.env`, que nunca se sube.

## Qué hacer
1. **Python 3.10 o superior.** El código usa `X | None`. Crear un entorno virtual en la raíz del repo: `python -m venv .venv`.
2. **Ollama:** instalarlo, `ollama pull qwen2.5:3b` y probar `ollama run qwen2.5:3b "hola"`.
3. **Neo4j 5.x:** Neo4j Desktop con una base local, o una AuraDB Free personal. Anotar URI, usuario y contraseña.
4. **Cargar el canónico completo** `docs/cypher/Grupo_2_PG2_U1_corregido.cypher` desde Neo4j Browser, con el editor multisentencia activado. Hasta que PG3-02 esté en `main`, esto alcanza para trabajar.
5. Cuando PG3-01 esté en `main`: `pip install -r requirements.txt`, copiar `.env.example` a `.env` y completarlo.
